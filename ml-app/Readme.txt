PREDICTIQ - MACHINE LEARNING PREDICTION WEB APPLICATION

PROJECT OVERVIEW
PredictIQ is a machine learning web application designed to make predictions using trained machine learning models. It provides a user-friendly interface for entering data and viewing prediction results.

PROJECT OBJECTIVES

Build a user-friendly web interface.

Apply machine learning models to prediction tasks.

Process user inputs and display prediction results.

INSTALLATION INSTRUCTIONS
Step 1: Install Python and Git.

Step 2: Download or clone the project repository.

Step 3: Open the project folder in VS Code.

Step 4: Create a virtual environment:

python -m venv .venv

Step 5: Activate the environment on Windows:

.venv\Scripts\activate

Step 6: Install the required dependencies:

python -m pip install -r requirements.txt

6. HOW TO RUN
Open the project folder in VS Code.

Run the appropriate Python application entry point from the terminal. The exact command depends on the backend file used in this project.

If the project uses Flask, the application may be started with:

python app.py

Use this command only if app.py is the actual application entry point.
